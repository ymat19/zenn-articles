## TL;DR

git worktreeを使う機会が増えてきたので、さっと切り替えられるようにしました。

fzfでブランチ選択→[gwq](https://github.com/d-kuro/gwq)でworktree作成→tmuxでセッション作成/スイッチ
↑を行うスクリプトをtmuxのpopup windowで実行してます

![gif](/images/ws.gif)
(ちょっと現実味がないぐらい忙しないですが、`greet.sh`, `fizzbuzz.sh`をClaude Codeを用いて並行で開発するようなシナリオで撮ってみたデモです)


## gwqとは

git worktreeって作るときも消すときもパスちゃんと指定しないといけないんですね。これが結構面倒です。
リポジトリ名やブランチ名から一意な命名規則で作れば良い話なんですが、ブランチ名には`/`が入っていたりしてなかなか一筋縄では行きません。
ところがgwqなら、`gwq add <branch name>`だけでよしなにworktreeを作ってくれます。`gwq list`で一覧取ったり`gwq remove`で消したりも、パスを意識せずにできます。
最高


## popup windowとは
popup windowとは、tmuxでpaneの上に矩形のウィンドウを表示できる機能です。
windowを何分割していようが、いつでもその上に大きいウィンドウを出せるのでとても便利です。
lazygitなんかをこれで呼び出せるようにしておくと最高。

## やってること

何をしているかというと↓だけです。worktreeやセッションがすでにあればそのステップはスキップされます。

1. fzfでブランチ選択
1. gwqでworktreeをadd
1. tmuxセッション作成してswitch


工夫したのはfzfに渡すリストです。↓の順番で表示されてます。

  - 既存worktreeのブランチ
  - ローカルブランチ
  - リモートブランチ

![list](/images/list.png)


## ソースコード

人によって環境が違うので、前項の仕様をAIに伝えて各々作ってもらったほうが多分良いです。

スクリプト本体
https://github.com/ymat19/dotfiles/blob/main/scripts/tmux-worktree-switcher.sh

キーバインド
```tmux.conf
bind w popup -d '#{pane_current_path}' -w90% -h90% -E zsh -c "source ~/.zshrc && ~/scripts/tmux-worktree-switcher.sh"
```
