## telescope.nvimのlive_grepとは

telescope.nvimとは、neovim界隈でデファクトスタンダードと言えるぐらい人気なファインダーです。

全文検索はlive_grepとして提供されており、動きはこんな感じ

![hoge](<https://devio2023-media.developers.io/wp-content/uploads/2022/07/telescope_live_grep.gif> =708x)

([telescope.nvimプラグインによるファイル検索・テキスト検索ライフ](https://dev.classmethod.jp/articles/nvim_telescope/)からお借りしてます)

grepが爆速にリアルタイムに反映されて、プレビューも見られる。

そして何よりカッコ良い

これに比べるとVSCodeさんのGrep機能はカスや......

## VSCodeでlive_grepしたい

やることは以下

1. CLIで動作するlive_grep的なものを用意する
2. VSCode上で、それを使えるようにする

## CLIを用意する

rgでgrepして、fzfで検索、batでプレビューをしたいだけなので、ざっくり言えば↓がしたい。

``` bash
    fzf --preview "bat <filename>" --bind "change:reload:rg <query>"
```

Roo Code, Claude 3.5 Sonnetが一晩でやってくれました。
<https://github.com/ymat19/live-grep-cli/tree/main>

良い感じにオプションなどを解釈しながら、上述のrg→fzf→batを連携するコマンドを実行してくれます。

## VSCodeで叩けるようにする

[multi-command](https://marketplace.visualstudio.com/items?itemName=ryuta46.multi-command)
[Command Runner](https://marketplace.visualstudio.com/items?itemName=edonet.vscode-command-runner)

こんな感じで呼び出す

``` json
{
  "key": "ctrl+shift+f",
  "command": "extension.multiCommand.execute",
  "args": {
    "sequence": [
      "workbench.action.terminal.focus",
      "workbench.action.toggleMaximizedPanel",
      "workbench.action.terminal.clear",
      {
        "command": "command-runner.run",
        "args": {
          "command": "clear && code --reuse-window -g $(live-grep -n -c 5)",
          "terminal": "runCommand"
        }
      }
    ]
  }
}
```
